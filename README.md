# Matthew Wong — Personal Portfolio

A responsive portfolio for Matthew Wong, an Innovation and Technology student at The University of Hong Kong. The site presents selected AI, hardware, and product projects using the supplied reports and event imagery.

## Run locally

This is a buildless static site. Open `index.html` directly, or serve the folder with any static server:

```bash
npx serve .
```

## Structure

- `index.html` — content and semantic page structure
- `styles.css` — responsive visual system and motion
- `script.js` — navigation, reveal effects, and project filters
- `ref/` — project source reports and supplied imagery

## Deployment

The site is compatible with GitHub Pages and any static hosting provider.
